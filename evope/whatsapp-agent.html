Agente de IA conversacional que permite aos clientes da EVOPE executar ações operacionais diretamente via WhatsApp — sem acessar o portal web. Autenticação, consultas e desbloqueio de máquinas em menos de 30 segundos.

O Problema

ℹ️

A EVOPE é uma plataforma SaaS de monitoramento de produtividade (evope.com.br). Seus clientes (empresas) precisam realizar ações operacionais como desbloquear computadores de colaboradores, consultar jornadas e verificar métricas. Hoje, isso exige acesso ao portal web portal.evope.com.br — gerando atrito de 3–5 minutos por ação.

ProblemaImpacto
Gestores precisam abrir portal, navegar, executar e voltar3–5 min de atrito por ação
Ações urgentes (desbloqueio) presas ao acesso desktopColaborador parado esperando
Clientes ligam/mandam email à equipe EVOPE por ações simplesCarga no suporte humano
API REST (v1.3.9, 20+ endpoints) não explorada conversacionalmenteSubutilização de infraestrutura

✅

Opção C — Híbrida é a recomendada. Já operamos workflows EVOPE no nosso n8n (agente mapa-processos, gerador de relatórios). Expertise em prompt engineering e LLM é da Digital AI. Ações críticas (desbloqueio) executam na infra EVOPE via API — segurança. Modelo SaaS natural: cobra-se pela orquestração + inteligência. Evolução independente: novos endpoints da EVOPE = registrar no agente; melhorias LLM = automáticas.

4User Stories #

US-01 Autenticação via WhatsApp F1 · F2
Como gestor de uma empresa cliente da EVOPE, quero me identificar no WhatsApp informando meu email corporativo, para que o agente reconheça quem sou e meu nível de acesso.
  • A1. Usuário envia email → agente valida via GET /user/{email} → confirma nome e perfil
  • A2. Email não encontrado → agente responde "Email não encontrado no sistema EVOPE."
  • A3. Sessão persiste por 24h (não pedir email a cada interação)
  • A4. Token EVOPE renovado automaticamente (TTL 30 min, renovar a cada 25 min)
US-02 Consultar Jornada de Colaborador F3
Como gestor, quero perguntar "qual a jornada do colaborador X?", para que eu veja horários, tipo de jornada, férias e folgas.
  • A5. Agente consulta /journey?IdentificationKey={key} e retorna resumo formatado
  • A6. Gestor só vê jornadas dos grupos aos quais tem acesso (campo groups do usuário)
US-03 Desbloquear Computador F4 — depende D-01
Como gestor, quero pedir "desbloquear a máquina do João", para que o colaborador volte a trabalhar sem que eu precise acessar o portal.
  • A7. Agente verifica se solicitante tem perfil Gestor ou Administrador
  • A8. Agente verifica se colaborador-alvo pertence ao grupo do solicitante
  • A9. Agente executa desbloqueio via endpoint API (a ser criado pela EVOPE — D-01)
  • A10. Agente confirma "Máquina de [nome] desbloqueada" ou reporta erro detalhado
US-04 Consultar Métricas de Produtividade F5
Como gestor, quero perguntar "como foi a produtividade da equipe esta semana?", para que eu tenha um resumo rápido sem acessar o portal.
  • A11. Agente consulta /activehoursreport para o período solicitado
  • A12. Retorna resumo: total horas ativas, média por colaborador, destaques
  • A13. Respeita limite de 31 dias por chamada (divide automaticamente se necessário)
US-05 Escalar para Humano F7
Como cliente da EVOPE, quero digitar "/humano" ou "falar com atendente", para que um atendente EVOPE assuma a conversa quando o agente não resolve.
  • A14. Agente transfere conversa para fila de atendimento humano
  • A15. Agente envia contexto da conversa ao atendente (resumo do que foi tentado)

#DependênciaResponsávelStatusImpacto

D-02 Endpoint listagem de máquinas por colaborador/grupo — necessário para saber QUAL máquina desbloquear. EVOPE (dev) NÃO EXISTE Bloqueia F4

D-05 Credenciais de API — Conta de serviço (email/senha) dedicada ao agente com perfil Administrador. EVOPE A CRIAR Bloqueia tudo

Riscos & Mitigações

#RiscoProbImpactoMitigação
R-01 EVOPE não cria endpoints de desbloqueio a tempo Alta Crítico Iniciar com consultas (Fases 0–2); ações entram quando endpoints prontos
R-02 Token JWT 30 min causa falhas de sessão Média Médio Renovação proativa a cada 25 min; retry com re-auth em 401
R-03 identificationKey não mapeável por email Média Alto Pedir GET /user/{email}/identificationKey ou padronizar key=email
R-04 Volume alto de mensagens → custo LLM elevado Baixa Médio Rate limiting; cache de respostas frequentes
R-05 LGPD — dados de produtividade via WhatsApp Média Alto Consentimento no onboarding; dados sempre agregados; compliance review
R-06 EVOPE muda API sem avisar (breaking change) Média Alto Versionamento; healthcheck periódico; gotcha no Cortex
