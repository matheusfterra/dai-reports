🎬 PROCESS STUDIO

Grava, documenta e re-executa processos

App desktop 100% local e individual (Windows, via Tauri) que transforma processos de trabalho no browser em documentação automática com IA — e, futuramente, em automação re-executável com variáveis editáveis.

O Process Studio é desenvolvido pela Digital AI e roda inteiramente no PC do usuário. Não há servidor próprio, conta, nem multi-tenant. A única saída de dados permitida é a chamada à API da OpenAI, usando a chave do próprio usuário armazenada localmente.

1Posicionamento de Mercado #

"Uma Scribe que executa." A Scribe (avaliada em US$ 1,3 bilhão) lidera o segmento de documentação automática de processos — mas só documenta, nunca re-executa. O Process Studio fecha essa lacuna.

2Funcionalidades Atuais #

Gravação de Browser (via CDP)

  • Conecta ao Chrome via Chrome DevTools Protocol (CDP)
  • Cria um perfil isolado para o Chrome com auto-detecção e relançamento automático quando a porta CDP morre
  • Captura por evento: clicks, digitação, navegação, screenshots
  • Captura requisições de rede correlacionadas — cada request carrega afterStepSeq para rastreabilidade passo a passo
  • Trace salvo em NDJSON append-only (nunca alterado após fechado)

Gravação de Tela Nativa

  • Usa ffmpeg empacotado (gdigrab + dshow — Windows)
  • Seleção de monitor e microfone na UI
  • Pílula flutuante clicável com tempo decorrido
  • Borda vermelha WDA_EXCLUDEFROMCAPTURE no monitor gravado
  • Saída em .mkv local
  • Recuperação de gravações órfãs após crash no boot

Documentação Automática por IA (F1)

  • Botão "Documentar" compila o trace em workflow.json + documento estruturado
  • GPT-4.1-mini com structured outputs estritos — fatos técnicos 100% do trace, sem invenção de dados
  • stripSecrets() remove dados sensíveis antes de qualquer prompt de LLM
  • Exportação em Markdown, HTML autocontido e PDF (Chrome headless)
  • Log auditável com tokens e custo USD por compilação

Documentação por Vídeo Local (FV)

  • Aceita qualquer vídeo local: .mp4 .mkv .webm .mov .avi
  • Extração local de frames e áudio via ffmpeg
  • Transcrição via Whisper-1 (OpenAI)
  • Chamadas de visão em janelas — suporta vídeos longos (até 120 min)
  • Aviso de privacidade obrigatório com confirmação antes de qualquer upload

9Princípios de Design — Constitution v1.1.0 #

Definidos em .specify/memory/constitution.md — imutáveis, só alteráveis por votação formal.

I
Local-First e Individual
Sem servidor próprio, sem conta, sem multi-tenant. Única saída de dados: API OpenAI com chave do usuário.
NON-NEGOTIABLE
II
Segredos Fora do LLM
Dados gravados em claro no disco (decisão do usuário). stripSecrets() obrigatório antes de toda chamada OpenAI. Exportação exibe ••••••.
NON-NEGOTIABLE
III
Replay Determinístico Primeiro, LLM Depois
Escada: seletor CSS → XPath → LLM heal → asserção de rede → intervenção humana. LLM proibido como cérebro de cada passo. Máx. 1 tentativa de heal por passo.
NON-NEGOTIABLE
IV
Trace Imutável, Workflow Versionado
NDJSON nunca alterado após fechado. Heals e edições geram v<N+1>.json. Recompilar gera workflow com ID novo.
NON-NEGOTIABLE
V
Herança por Fork
Código originado do relay (cortex-local-agent). O repositório de origem não é modificado.
VI
Correlação Explícita Passo↔Request
Cada request capturada carrega afterStepSeq. Traces antigos sem o campo compilam sem asserções, com aviso.
VII
Transparência de Custo de IA
Toda chamada LLM registra tokens e custo estimado no log local. A UI exibe esses valores. Nenhuma chamada de IA silenciosa.
NON-NEGOTIABLE

12Build e Deploy #

⚠️

Pré-requisitos: Windows 10/11 x64 + Google Chrome + Node.js 20+ + Rust estável (MSVC Build Tools) + WebView2

POWERSHELL
npm install
npm run fetch:ffmpeg                               # baixa ffmpeg LGPL (~110 MB)
cd sidecar
npm install
npm run build:win                                  # gera sidecar .exe via pkg
cd ..
Copy-Item sidecar\sidecar-x86_64-pc-windows-msvc.exe src-tauri\sidecar\
npm run tauri:dev                                  # desenvolvimento
npm run tauri:build                                # instalador NSIS

Saída: src-tauri/target/release/bundle/nsis/ — instalador NSIS Windows.

Notas Críticas de Build

  • ffmpeg.exe (~110 MB) não é versionado no git — baixar via npm run fetch:ffmpeg
  • Playwright pinado em 1.59.1 para compatibilidade com @yao-pkg/pkg
  • Sempre validar com o exe empacotado, não apenas node index.js
  • Testes do sidecar: cd sidecar && npm test
